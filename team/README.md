# Allemann × Leffler — Sponsor site

Standalone, sponsor-facing Beachvolleyball team page. It intentionally contains only sport-related material; Simon Leffler's academic portfolio remains on the parent site.

## Local preview

```sh
cd team-sponsoring-site
python3 -m http.server 8000
```

Open `http://localhost:8000`.
